## Synthesis for Forge

- **Glass only on the floating layer.** Translucency/blur + a thin specular edge belong on the top bar, Ctrl-K palette, and modals — never on lesson content, code, or text cards. (Apple-materials principle; reinforced by Raycast's floating-panel pattern.)
- **Depth from hairlines, not shadows.** Prefer a single `1px` warm-neutral hairline plus a subtle surface-lightness step for elevation on sidebar/cards/chips (Linear-style), keeping the flat, minimal look. *(1px / opacity values TYPICAL.)*
- **One motion-token set, restrained.** Standardize a small duration/easing scale — hover `~120–160ms ease-out`, press `~90ms`, reveal/spring `~300–500ms` with slight overshoot — and reuse it everywhere. *(All TYPICAL; no site exposed real timing values.)*
- **Teach-first interactivity.** Embed small, single-purpose interactive widgets inline; let the learner **scrub/drag at their own pace** with no autoplay; use ghost trails and guidance cues (Ciechanowski + Josh Comeau).
- **Predict → interact → reveal as an explicit pattern** for the Predict step and review deck — but note this was a design decision, not confirmed on Brilliant's loaded page; what *was* present there is "hint before answer."
- **Hero = product preview over a soft warm gradient** with a tight 2-line type hierarchy (Clash Display headline + Satoshi subhead) and two CTAs (Stripe composition, Forge palette).
- **Celebrations are short and warm.** Animated count-up for XP/streak chips and a brief (<`1.5s`) lesson-complete beat with an Ember mascot reaction — avoid guilt-driven or loud sustained gamification. *(Timing TYPICAL.)*
- **Loader: fast, staggered, skippable.** A short Ember beat then a staggered cascade (sidebar → hero → cards); borrow sequencing logic only, not long agency-style intros. *(Stagger values TYPICAL.)*
- **Honesty of sourcing:** none of these numeric style values were measured from live CSS (the fetch tool strips styles); Apple, Duolingo, and Codrops did not provide usable content. Verify any value in-browser (devtools) before encoding it as a Forge token.
