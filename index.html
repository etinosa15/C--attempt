Your academy has its own server.

Live Server serves static files. Forge also compiles and runs C#, so it needs the included Node.js server to power the complete app.

  1. In this project folder, double-click Start Forge.cmd in File Explorer, or run npm start in the VS Code terminal.
  2. Keep that terminal window open, then open your academy below.
Open Forge Academy   → http://localhost:4317

If Forge is already running, just choose Open Forge Academy. If the browser says it cannot connect, complete step 1 first. Use this same academy address each time to keep your saved progress together.
